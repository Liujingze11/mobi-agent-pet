These files are source backups. They are not packaged with the application.

| Version | Description | Status |
| --- | --- | --- |
| `v1-devpulse-purple` | Legacy purple DP AI mark from the retired Linux app | Archived |
| `v2-blue-ring-white` | First blue ring with an opaque white background | Archived |

the PWA and Linux tray variants used by its release.

directory. Nothing in this history directory is packaged with the app.
