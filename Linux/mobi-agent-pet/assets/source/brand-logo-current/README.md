# Approved Brand Logo

This directory is the source snapshot for the approved AgentLog Pet logo:
the transparent, outward-thickened blue ring.

The matching runtime exports live under `assets/brand`,
`runtime/clawd/pwa/icons`, and the normal entries in
`assets/tray-icons/hicolor`. Automated tests compare every active export with
this snapshot. Colored tray status lights are operational state assets rather
than alternate brand logos.
