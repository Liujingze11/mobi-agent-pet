# 更新记录

## 0.1.29 — 2026-10-08

- 供应商主页面按 CC Switch 的工具切换与供应商卡片结构重排，先展示 Claude Code、Claude Desktop、OpenAI 三个入口；OpenAI 对应本地 Codex 配置。
- 卡片显示接口域名和配置的模型，当前使用项以浅蓝边框和状态标签突出；添加、导入导出放在顶部，排序和余额设置收进更多操作。
- 支持键盘切换入口与窄窗口布局；防止旧入口的异步操作结果覆盖新入口状态。
- 取消并打开新供应商草稿或余额设置后，旧保存结果不会关闭新表单。
- 列表仅返回公开连接摘要，接口中的账号、密码、路径和查询参数不进入卡片；保留原有加密配置与切换流程。

## 0.1.28 — 2026-10-08

- 共存型供应商支持配置标识，保存实际写入的标识；兼容旧版本已启用记录，移出时不会误删未管理的同名配置。
- 获取模型后，将模型加入所选工具的原生模型列表或 Claude Desktop 路由，重复选择不会重复添加；Codex 多供应商配置按当前选中路由编辑，Grok 原生配置可以补齐凭据。
- 默认导出剔除伪装为模型字段的凭据，同时保留配置标识、Hermes 协议及经过凭据清理的 Codex/Grok TOML。
- 增加独立桌面验证脚本，覆盖供应商加密保存、重启、配置写入、移出、编辑删除与导入导出。

## 0.1.27 — 2026-10-08

- 自定义供应商按 Agent 生成原生配置骨架；修正 OpenCode、MCode、Hermes 密钥和接口地址的写入位置。
- 共存型工具的表单可添加、删除、改名模型，并直接编辑常用 API 协议或 SDK 包；保留模型的其他配置字段。
- 长密钥在逐项编辑区始终遮盖显示，窄窗口下的配置字段改为单列。

## 0.1.26 — 2026-10-08

- 供应商卡片支持调整顺序，顺序保存在本机数据库中。
- 增加供应商列表的 JSON 导入导出。默认导出只保留识别出的公开配置字段；密钥和未知字段不进入备份，导入项须检查并补齐凭据后才能启用。
- 添加表单增加逐项编辑预设配置的入口，可修改各工具已有的模型、路由及其他嵌套字段，保留完整配置 JSON 供新增复杂字段使用。

## 0.1.25 — 2026-10-08

- 供应商页和桌宠空间增加余额或剩余额度展示，只显示当前启用的切换型供应商及已加入 Agent 的共存型供应商；保留查询时间和过期提示。
- 增加 DeepSeek、阶跃星辰、硅基流动、OpenRouter、Novita 的内置余额查询，以及可指定 HTTPS 地址和 JSON 数值字段的自定义规则；不支持的接口不显示猜测金额。
- 切换供应商时同步刷新桌宠数据；当前 Agent 配置的原文不再传给编辑页面。

## 0.1.24 — 2026-10-08

- 供应商记录可写入 Claude Code、Codex、Gemini CLI、Grok Build、Claude Desktop 的实际配置，OpenCode、OpenClaw、Hermes、Pi、MiniMax Code 支持分别加入或移出配置。
- 切换采用私有备份、原子写入、失败恢复与启动恢复；支持恢复原配置，并在外部修改连接字段时阻止覆盖。Claude Code 的无关 Hook 修改可在切换时保留。

## 0.1.23 — 2026-09-30

- 应用界面新增「供应商」页，可为 CC Switch 支持的十种 Agent 工具添加、编辑和删除供应商，保留全部预设及其结构化配置。
- 通用网关配置可生成 Claude Code、Codex、Gemini CLI 的对应记录；保存的密钥使用系统安全存储加密，不安全后端仅允许保存已知的无密钥官方配置。
- 本版先提供供应商配置管理；实际切换 Agent 配置和余额展示将在后续版本接入。

## 0.1.22 — 2026-09-30

- 「桌宠空间」额度卡片改为显示剩余百分比和剩余进度条，折叠摘要显示各来源与时间窗口中的最低剩余值。
- 剩余量较低时显示提醒；保留旧数据和重置时间的提示，不把过期数值当作实时不足。
