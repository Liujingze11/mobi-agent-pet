# Mobi Agent Pet v0.1.30

本次更新集中优化角色、动作管理和桌面动画。

- 重新打磨莫比、莫莫、比比的思考、打字、搭建、清扫、搬砖、走路、报错、休息与提起动作，移除已退役动作及旧版迷你系列，当前共保留 43 个动作。
- 三位角色各新增框内彩纸雨和整屏彩纸雨；完成状态默认播放框内版，整屏版可在动作库中单独选用。
- 每个角色的七种状态各配置一个默认动作，其他动作继续可选；已保存的自定义搭配保留，点击“恢复默认”即可使用新的推荐搭配。
- 优化动作管理的布局、背景、角色名称、预览和操作提示，统一页面标题、角色当前标记和简介。
- 将主题入口改为角色，移除不支持的角色导入、自动同步、链接协议及对应后端代码。
- 更新办公场景，完善自定义模式的折叠、说明、帮助图示和额度选项；修复概览在文字缩放下的尺寸计算。
- 补齐供应商模块的正式运行依赖，修复安装包启动时缺少 JSON5 模块的问题。
