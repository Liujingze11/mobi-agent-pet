## 源码与版本

应用 package.json、package-lock.json 及 lock 根包版本均为 0.1.30；内嵌 Clawd 的上游版本标识保留 0.13.0。三角色共 43 项动作，每个角色七种状态各有一个默认动作。新增模块、角色 SVG、帮助图示和办公场景素材均包含在正式包中；退役 mini 资源和角色导入模块已移除。

## 安装包

当前主机缺少原生托盘编译所需的 GTK、Ayatana AppIndicator 和 JSON-GLib 开发包。本轮 native 源码未变，复用已有 build/tray；正式 verify-linux-tray-bundle.cjs 对协议、动态依赖、图标及校验值验证通过。Manager 已构建、sidecar 已验证后，执行 node scripts/build-linux.cjs 成功生成 AppImage 和 deb。

首次安装包启动发现 json5 仅作为开发依赖间接存在，导致供应商模块加载失败。将已有 json5@2.2.3 列为正式依赖并同步 lock 后，337 项应用测试再次通过，重新生成两个安装包。

- app.asar 的应用版本为 0.1.30，包含 json5@2.2.3；角色素材数量分别为 14、14、15，七状态默认配置完整。
- deb 元数据：mobi-agent-pet / 0.1.30 / amd64。
- AppImage：smoke:linux 启动和第二实例激活通过，4 个窗口，原生托盘 native。
- AppImage：smoke:manager 通过，Manager 壳、窗口标题及 agentlog.db 均正常。
