# 三种模式：桌宠显示

用户已确认本轮只调整桌宠显示及状态范围，沿用其他模式规则。

| 模式 | 显示 | 状态范围 |
| --- | --- | --- |
| 常规 | 显示桌宠 | 空闲、漫游、工作、等待、完成、错误、被提起 |
| 后台 | 隐藏桌宠 | 不展示状态动作 |
| 自动 | 显示桌宠 | 空闲、工作、等待、完成、错误、被提起；关闭漫游 |

## 实现

- 模式策略使用共享七状态枚举；自动模式允许等待，拒绝漫游，拒绝时不覆盖待恢复任务。
- 主窗口可见性由模式强制决定。返回常规/自动时显示；后台不能由旧显示 API、快捷键或恢复逻辑重新显示。
- 常规在空闲且满足原漫游条件时启用漫游；自动/后台禁止启动及继续移动。旧 `freeRoam` 偏好保留为兼容数据，不能覆盖模式。
- 移除独立显示/隐藏、漫游开关及隐藏快捷键界面；旧隐藏快捷键不注册，旧行为写入口拒绝漫游修改。
- 状态中的动作配置、排序、随机播放和素材替换继续生效。声音、气泡、权限自动化、托盘及 HUD 策略留到后续讨论。
