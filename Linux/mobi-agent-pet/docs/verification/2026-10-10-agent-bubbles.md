# Agent 气泡合并与配色验证

日期：2026-10-10。按用户确认的方案实施，并按后续要求精简重复文字。

## 最终规则

| 模式 | 桌宠 | Agent 气泡 | 托盘提醒 |
| --- | --- | --- | --- |
| 常规 | 显示七状态 | 开启 | 开启 |
| 后台 | 隐藏 | 开启，手动审批 | 开启 |
| 自动 | 显示六状态，不漫游 | 关闭 | 开启 |
| 自定义 | 按独立配置 | 一个统一开关 | 按独立配置 |

气泡涵盖审批、被动通知、问答和计划确认；原有各 Agent 的交互能力、自动审批授权边界和卡片停留时间规则保留。后台模式不再自动开启免打扰，否则气泡和托盘开关仍会被阻断。自动模式中不能自动处理的请求回到原生交互，不创建气泡，也不遗留无界面的待处理请求。

“跟随桌宠”设置和运行时定位分支已移除。卡片始终位于桌宠所在屏幕的工作区右下角，按先后顺序向上堆叠；多屏偏移、超高堆叠和远程审批条目过滤继续生效。旧跟随偏好保留为兼容数据，不产生运行效果。

旧自定义配置迁移为 `agentBubbles`：两个旧开关任一开启时保留开启；两者均关闭则保持关闭。旧跟随字段丢弃，其余合法选项保留。新编辑器只提供一个 Agent 气泡开关。

## UI

新增 `agent-card-style.js`，概览及气泡使用同一份 Agent 调色板，包括既有 Agent 的固定颜色及其他 Agent 的稳定散列配色。白色卡片、浅灰内容区与概览保持一致，侧边线、标识和主按钮采用来源 Agent 的颜色；工具类型不再决定配色。卡片消息携带来源 Agent 标识。

Agent 名称只出现一次；普通通知标题改为“通知”，移除重复的 Agent 工具标签。单道问题不显示重复题头、`1 / 1` 或不可用的“上一步”；多题翻页、多选、其他文字回答及提交功能保留。

原有托盘控制器的闪烁时序未变。隐藏桌宠时从已接收的 Agent 事件继续触发完成/错误提醒，兼容旧完成事件名，并保留待审批提醒优先于完成提醒的处理。
