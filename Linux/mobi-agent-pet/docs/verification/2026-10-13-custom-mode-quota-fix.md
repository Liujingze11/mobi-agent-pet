# 自定义模式：独立额度开关与名称统一 — 2026-10-13

## 结果

自定义模式关闭任务卡片、开启额度提示时，双击桌宠现在可以只显示额度环。关闭额度提示会立即收起额度环；也可只显示任务卡片。常规模式及后台/完全访问模式维持原有显示规则，保存配置不切换当前模式。

自定义审批方式的「无人值守」改为「完全访问」，英文改为 Full Access。此前模式菜单、启用确认标题及按钮的五语言改名保留；内部 automatic / unattended 标识不变，不改变 Agent 权限或审批行为。

## 修复位置

- app-mode.js 输出有效的额度显示策略：常规模式开启、自定义模式服从 hudQuota、后台和完全访问模式关闭。
- main.js 的 HUD 上下文直接读有效额度策略，不再通过卡片 suppressSessionHud 开关覆盖额度。模式切换期间也使用目标模式的投影，避免读取上一模式缓存。
- custom-mode-editor.js 仅更新审批方式名称，不变更保存、确认、回滚、状态选择或布局。

## 验证

- 新回归先失败：真实主程序额度 getter 将自定义 quota-only 组合改为 false；编辑器仍显示 Unattended。
- 修复后相关回归：140 通过、1 跳过、0 失败。
- 完整 `npm run test:phase2` 退出 0：AgentLog 316、Manager 79、桌宠 6441，共 6836 通过、22 跳过、0 失败。Manager 类型检查及构建通过。
- 隔离原生脚本 `scripts/verify-automatic-mode.cjs` 退出 0，输出 AUTO_ALL_FEATURES_NATIVE_PASS。原有九组模式/状态/拖拽/审批/唤醒场景继续通过，新增真实自定义编辑器保存与独立窗口场景：仅额度、都关闭、仅卡片、返回完全访问模式后都隐藏。
- 实际编辑器显示「完全访问」；保存时仍保持原模式，300 秒漫游间隔等其他值保留。Agent 权限与集成安装状态未修改。
- 独立只读复核未发现实质问题，65 项相关测试通过；额外验证目标模式切换投影和固定模式内保存自定义配置的边界。
- 原生测试使用私有配置和模拟额度数据，阻止 Agent 命令执行，不操作用户鼠标或实际配置。不是所有 Agent、物理多屏或全屏应用的实机测试。

功能与命名以外的界面布局未改，已删除功能仍不加入编辑器。
