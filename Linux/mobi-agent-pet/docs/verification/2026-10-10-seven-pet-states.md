# 桌宠七状态统一验证

日期：2026-10-10。实施方式：当前会话顺序实施，结束时独立整体复审。

## 实现范围

桌宠运行状态统一为 `idle`、`roam`、`working`、`waiting`、`complete`、`error`、`held`。共享契约用于主进程、页面和播放器；Agent 会话和历史事件保留原始细分语义。

- 默认及已保存配置经过同一个有效动作方案，未保存时也立即生效。跨状态分配素材不改变逻辑状态；空槽回落空闲，缺失项在内存中过滤。
- 主进程拥有提起覆盖、任务恢复、完成/错误期限和主题代数/状态修订号；渲染帧必须匹配当前快照及启用动作。
- 点击、连击、文件拖入及旧桌宠预览不能自由插播素材。动作预览保留在管理卡片中。
- 贴边、探头、省电和窗口几何使用独立显示参数；不创建 `mini-*` 或睡眠/眩晕业务状态。
- 保留 Agent 检测、会话记录、完成防抖、权限请求和终端跳转。本次没有决定自动模式应保留哪几个状态。

## 工作区与实施决策

保留已有 `feature/two-metric-usage` 工作区中的大量未提交改动。实施前的源代码、测试和主题快照在 `/tmp/mobi-seven-baseline`；本任务源码未与用户已有改动捆绑提交。

1. 使用现有工作区及基线快照，避免干净分支遗漏用户实现。代价是隔离程度较低。
2. 受限沙箱下 Node 子进程隔离可能只报文件总数；完整测试用已批准的普通隔离执行，单文件失败探针用 `--test-isolation=none`。只采信实际用例统计。
3. 完成/错误使用有效动作原生时长；旧主题未声明时长时默认 5 秒。代价是相较旧固定 4 秒略长。
4. 删除独立鼠标睡眠链及未配置点击/拖入反应。代价是这些未配置视觉反馈不再自动触发。
5. 同时存在等待与无关完成事件时，等待优先；完成事件继续记录。代价是等待未解决时不展示该完成动作。
6. 复审未判断原生透明窗、真实捕获丢失及跨屏外观；以逻辑夹具验证，不声称手动桌面验收。代价是实际桌面观感问题可能仍需实机排查。
7. 自动模式产品取舍按用户要求留待后续讨论；本次保持已有策略。代价是本次统一不改变已有模式的状态抑制规则。
8. 对已有未提交代码只审查与七状态相关的交互，不扩大改写范围。代价是独立复审不能替其他功能提供审查保证。
9. 对 reviewer 未定级的其他窗口 drag-end，按主进程提起所有权要求处理并补来源校验，不作安全威胁结论。代价是旧的非输入窗释放调用会被拒绝，当前生产调用来自输入窗。
10. 清扫/搬运保持原 Agent 会话和记录语义，桌宠以剩余真实任务解析结果为准。代价是没有活动任务时不单独闪现工作画面。
11. 默认空闲素材也全部失效时，拒绝加载该方案/主题并按加载器机制回落。代价是损坏的主题无法继续显示；不会选择不可用素材。
12. 完成后保留未提交源码及本计划执行记录，不在没有源码提交的情况下删除恢复依据，也不合并/推送已有功能分支。代价是后续集成仍需分离本任务与用户已有差异。
