# 供应商页面 0.1.29

## 已确认的页面范围

参考 CC Switch v3.20.4 的顶部应用切换与供应商卡片结构；此阶段仅显示 Claude Code、Claude Desktop、OpenAI。OpenAI 是界面名称，对应现有 Codex 本地配置适配器。

顶部提供 Agent 图标和终端／桌面角标，右侧放添加与导入导出。下方卡片显示供应商名称、接口域名、配置模型、余额与当前使用状态。启用、编辑和删除位于右侧；排序和余额规则放入更多操作。

公开列表摘要由主进程从已保存配置生成，只返回接口域名和明确的模型字段。接口中的账号、密码、路径、查询参数不进入卡片。安全存储无法解密时仍可读取供应商名称；读取完整配置继续要求成功解密。

- `npm run test:phase2`：退出码 0；后端 296 项通过，管理界面 79 项通过，上游 6327 项通过、22 项跳过；类型检查与页面构建通过。

- 视觉检查：1160×760 与 640×860 截图已人工检查，无横向溢出，卡片在窄窗口下分行显示操作。
