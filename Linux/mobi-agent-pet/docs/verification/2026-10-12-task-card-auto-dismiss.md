# 任务卡片 5 秒自动收起

用户最终要求等待几秒自动消失、点击外部空白处也消失，并选择 5 秒。该规则替换上一轮持续展开规则；双击容错、实际拖动及手势结果隔离保留。

窗口实际可见后为未固定卡片启动 5000ms 定时器。数据同步和位置更新不续期；再次双击重新获得 5 秒。外部点击或实际拖动立即收起。固定卡片不计时，取消固定后重新计时；仅额度环也使用同一规则。收起、模式失效、固定和清理均取消定时器；旧句柄不能关闭重新展开的卡片。
