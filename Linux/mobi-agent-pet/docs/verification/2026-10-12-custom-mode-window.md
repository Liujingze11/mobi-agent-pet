# 独立自定义模式编辑器

## 结果

“编辑自定义模式”从设置中移出，通过托盘的模式菜单打开独立的 620 × 720 小窗口。重复打开复用同一窗口；允许调整大小、滚动查看内容，底部始终保留保存和恢复默认按钮。沿用当前界面的浅色、白色卡片与蓝色开关。

14 个布尔功能与 7 个状态均使用可通过键盘操作的滑动开关。空闲状态固定开启，数字项和三选一审批方式保留原有含义。配置分为桌宠显示、提醒与审批、任务卡片、省电与唤醒、窗口行为。

桌面宠物中的“桌宠行为”仅有跳转按钮，因此删除该页面、样式、IPC、无用翻译及未挂载的旧声音编辑模块。桌面宠物保留概览、动作管理、主题。

配置仍经 settings controller 的自定义模式命令保存，不改变模式，也不允许编辑前三种固定模式。沿用原有保存队列、运行时失败回滚与自动审批确认逻辑。独立 preload 仅提供配置读取、保存及相关设置变更订阅。

## 验证

- 修改现有测试后先确认失败：布尔控件没有 switch 语义、旧行为页仍占据导航、托盘编辑命令打开设置、窗口尺寸仍为设置默认值。
- 完整 `npm run test:phase2`：6835 通过、22 跳过、0 失败；管理界面类型检查和构建通过。
- 最后清理无用翻译及接口后的相关回归：266 通过、0 失败，覆盖编辑、保存与确认、窗口、托盘、桌面宠物导航、设置 IPC、多语言和浏览器环境。
- 通过隔离 userData 的真实 Electron 窗口加载独立 HTML、renderer 与 preload，验证 21 个滑动开关、7 个状态、空闲不可关闭、无设置侧栏、底部保存按钮可见、内容可滚动、重复打开复用窗口、语言切换保留未保存改动、保存配置、取消及确认自动审批、窗口关闭清理。无渲染错误。
- Electron 检查使用受控配置后端，并未修改当前用户配置；生产保存与回滚由 IPC 回归测试验证。截图已检查，未进行各平台实体鼠标验收。
- 独立只读代码审查未发现本次改动的问题；审查者另行运行 72 项相关测试，全部通过。
