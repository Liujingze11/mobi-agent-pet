# 自定义模式：功能分组与模式模板

2026-10-13。用户指定主要功能为原清单 1、2、3、4、5、8、9：显示桌宠、托盘图标提醒、桌面通知与审批、审批方式、桌宠任务卡片、允许的七种状态、漫游间隔。

顶部加入常规模式、后台模式、完全访问模式、重置四个按钮。前三个按钮将对应模式的完整配置填入本地草稿，用户可修改后保存为自定义模式。按钮不会切换当前运行模式或立即写入偏好。重置恢复原有自定义模式默认值，也要保存后才写入。

`custom-mode-profile.js` 的 `builtInModeProfile` 是固定模式与编辑器模板的同一份配置定义。它为每次调用返回新的可编辑副本，含新的状态数组。常规、后台、完全访问实际行为保持原样；包含工作防休眠和跨屏大小的固定开启，以及后台/完全访问隐藏额度的既有规则。后台仍保留状态选择，显示桌宠关闭时不会渲染这些状态；用户打开显示后可继续调整。

其他十项放在“更多设置”中，默认只折叠这一层。内部气泡与闪烁、卡片与额度、电脑与窗口三个分区直接显示。原有五项真实截图帮助继续保留。模板切换保留展开状态；保存期间所有模板/重置按钮禁用。常规窗口七种状态用四列呈现，小窗口改为两列并可滚动。
