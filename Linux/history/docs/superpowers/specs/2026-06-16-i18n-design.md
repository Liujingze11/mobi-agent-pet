# i18n 国际化设计

**日期**: 2026-06-16  
**状态**: 已批准

## 目标

将 DevPulse AI 从中英混合硬编码改造为完整国际化，支持中文（默认）和英文，首次启动弹窗选择语言，设置中可随时切换。

## 架构

```
src/lib/i18n/              ← 渲染进程翻译
  ├── index.tsx            ← I18nProvider + useI18n hook + LanguageGate
  ├── zh-CN.ts             ← 简体中文翻译
  ├── en-US.ts             ← 英文翻译
  └── types.ts             ← TranslationMap 类型

electron/i18n.ts           ← 主进程翻译（t 函数）
```

## 数据流

1. **首次启动**: GUI 检测 `app_settings.language` 为空 → 显示 LanguageGate 选择页
2. **选择后**: 存入 `app_settings.language`，设置 React Context
3. **后续启动**: 从 settings 读取语言，直接渲染
4. **切换**: Settings 页面切换 → 更新 Context + 存入 settings → 全应用即时响应
5. **主进程**: 通过 IPC `settings:get` 获取语言，渲染菜单/AI prompt

## 翻译文件结构

每种语言一个文件，export 一个嵌套对象。key 按 `模块.页面.元素` 命名：

```typescript
// zh-CN.ts
export const zhCN = {
  app: { name: 'DevPulse AI', ... },
  pulsecore: { 
    status: { idle: '空闲', working: '工作中', ... },
    forms: { energyCore: '能量核心', ... },
    quickPanel: { startWork: '开始工作', ... },
  },
  gui: {
    sidebar: { ... },
    overview: { ... },
    projects: { ... },
    ...
  },
  tray: { startWork: '开始工作', ... },
  seed: { categories: [...], achievements: [...] },
}
```

TypeScript 类型从 `zh-CN.ts` 推导，确保 `en-US.ts` 结构一致（编译时检查）。

## 实现步骤

### 1. 创建翻译文件
- `src/lib/i18n/types.ts` — TranslationMap 类型（从 zhCN 推导）
- `src/lib/i18n/zh-CN.ts` — 中文翻译（从现有代码提取）
- `src/lib/i18n/en-US.ts` — 英文翻译

### 2. 创建 i18n React 层
- `src/lib/i18n/index.tsx` — I18nProvider, useI18n hook, LanguageGate 组件
- LanguageGate: 首次启动时显示语言选择 UI，选择后消失

### 3. 改造前端组件
- 所有硬编码中文 → `const { t } = useI18n()` + `t('key.path')`
- 涉及文件: ~15 个组件

### 4. 改造主进程
- `electron/i18n.ts` — 同步翻译函数（从 DB 读语言设置）
- 托盘菜单、右键菜单 → 动态生成
- AI prompt → 根据语言调整

### 5. 改造种子数据
- 学习分类名、成就名/描述 → 双语存储
- 或在 seed 时根据语言设置选择

### 6. Settings 页面添加语言选项
- 新增 Language 下拉选择框

## 语言持久化

- 存储位置: `app_settings` 表，key = `language`，value = `"zh-CN"` | `"en-US"`
- 主进程读取: 同步 `getSetting(db, 'language')` 
- 渲染进程读取: IPC `settings:get('language')`

## 种子数据处理策略

种子数据（分类名、成就名）在数据库中是固定的。方案：
- seed.ts 读取当前语言设置
- 根据语言写入对应翻译
- 如果用户之后切换语言，已存入 DB 的名称不变（新创建的会使用当前语言）
- 成就名称在 checker.ts 中动态翻译（从翻译文件读取，而非 DB）
